# MCP Конфигурация для Claude Code

## Установка

1. **Скопируй конфигурацию в Claude Code:**

```bash
# Windows
copy mcp-config.json %USERPROFILE%\.claude\mcp_settings.json

# Linux/Mac
cp mcp-config.json ~/.claude/mcp_settings.json
```

2. **Перезапусти Claude Code**

3. **Проверь подключение:**
   - В Claude Code набери: "Какие MCP инструменты доступны?"
   - Должны появиться 9 SEO-инструментов

## Доступные инструменты

### 1. analyze_html
Полный SEO-аудит HTML страницы (title, meta, H1-H6, тошнота, Schema.org).

**Пример:**
```
Проанализируй SEO страницы https://example.com
```

### 2. check_text
Анализ текста: тошнота, плотность ключей, топ слова.

**Пример:**
```
Проверь текст на тошноту: "ремонт квартир в Москве..."
```

### 3. suggest_keywords
Яндекс.Suggest — подсказки для семантики.

**Пример:**
```
Собери семантику для "ремонт квартир"
```

### 4. parse_competitor
Загрузить конкурента через Playwright (с JS), сохранить HTML, провести анализ.

**Пример:**
```
Спарси конкурента https://competitor.ru
```

### 5. rag_search
Векторный поиск по базе знаний Яндекса (без AI генерации).

**Пример:**
```
Найди в базе знаний информацию про поведенческие факторы
```

### 6. rag_ask
Вопрос к базе знаний с AI генерацией ответа через LM Studio.

**Пример:**
```
Что Яндекс говорит про алгоритм Проксима?
```

### 7. get_wordstat
Частотность запроса в Яндекс.Вордстат через XML API.

**Пример:**
```
Какая частотность у запроса "натяжные потолки"?
```

### 8. list_competitors
Показать список сохранённых конкурентов.

### 9. rag_index
Переиндексировать базу знаний.

## Требования

- **LM Studio** должен быть запущен на `localhost:1234`
- **Модели загружены:**
  - `qwen/qwen3-vl-4b` — генерация
  - `text-embedding-nomic-embed-text-v1.5` — эмбеддинги
- **API-ключи** в `00_ЯДРО/.env`:
  - `YANDEX_OAUTH_TOKEN` (Вебмастер)
  - `YANDEX_XML_KEY` (парсинг выдачи)
  - `TEXTRU_API_KEY` (уникальность)

## Тестирование

Запусти тест инструментов:
```bash
seo.bat mcp-test
```

Или запусти MCP-сервер вручную:
```bash
seo.bat mcp
```

## Troubleshooting

**Проблема:** MCP-сервер не запускается
- Проверь, что `.venv` активирован
- Проверь путь к Python в `mcp-config.json`

**Проблема:** RAG не отвечает
- Убедись, что LM Studio запущен: `curl http://localhost:1234/v1/models`
- Проверь, что база проиндексирована: `seo.bat rag-status`

**Проблема:** Ошибки кодировки
- Уже исправлено в `config.py` (UTF-8 wrapper)
